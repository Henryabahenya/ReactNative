# RateRepos
itoryApp

RateRepositoryApp is a React Native repository review application built with Expo, React Native, Apollo Client, and GraphQL. It allows users to browse repositories, filter/sort listings, view details, sign in/up, create reviews, and manage their own review entries in a clean mobile-first interface.

## Features
- Browse a list of repositories with live search filtering and sorting
- View repository details, review lists, and external GitHub links
- User authentication (Sign in & Sign up with automatic sign-in)
- Create, view, and delete personal reviews with validation
- Built with React Native, Expo, and GraphQL
